# Assets Folder

This folder contains images and other assets used by the Snake AI Trainer application.

## Default Training Logo

Place a default training logo image here named `snake_logo.png` for it to be automatically loaded when the TrainerWindow opens.

Supported formats:
- PNG (recommended)
- JPG/JPEG
- BMP

Recommended image size: 400x400 pixels or similar square aspect ratio for best display.

## Custom Images

You can also select custom images at runtime using the "Choose Custom Image" button in the TrainerWindow.
